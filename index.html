Connect real email

Connect directly to Google or Microsoft to read and send mail, add senders to contacts, and archive or move conversations to Trash with your permission. Nothing is permanently deleted. Data is cached in this browser's IndexedDB, never on a Gather server. Tokens remain in this tab's memory. Do not connect on a shared device.

Opening a conversation marks it read at the provider when mail-modification permission is granted. Conversations open as plain text. Switching to HTML asks whether to display images; you can decline and load them individually later. HTML is sanitized and isolated. Remote image hosts may learn your IP address and that you opened the email. Scripts, forms, and other attachment downloads remain blocked. Links require confirmation. Closing the app stops sync.

OAuth setup requirements

Register a Google Web application client, enable Gmail API and People API in the same Google Cloud project that owns that client ID, and add your account as an OAuth test user. Granting OAuth permissions does not enable these APIs. Authorized JavaScript origin:

Register a Microsoft application allowing personal Microsoft accounts (and organizational accounts if needed). Add a Single-page application redirect: . Grant delegated User.Read, Mail.Read, Contacts.Read, Mail.Send, Mail.ReadWrite, and Contacts.ReadWrite permissions. Google requests gmail.readonly, contacts.readonly, gmail.send, gmail.modify, and contacts. Existing accounts must reconnect to grant conversation-action permissions. Do not create or enter a client secret.

Use an HTTPS static host for deployment. If sign-in is blocked in the preview panel, open the same URL in your regular browser. All provider mail folders and Gmail labels are imported, including drafts, junk/spam, and deleted/trash. Mail import starts from the chosen date range; subsequent syncs catch up from that starting date.

Add multiple Gmail and Outlook accounts. Choose a different account in the provider's sign-in window. Only one public application ID is needed per provider; each mailbox has its own authorization and cached mail.
